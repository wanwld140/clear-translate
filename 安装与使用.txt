清译_V5 · Chrome / Edge 自动识别外语双语翻译

安装
1. 解压“清译_V5.zip”，把“清译_V5”文件夹放在准备长期保留的位置。
2. Chrome 地址栏打开 chrome://extensions；Edge 打开 edge://extensions。
3. 开启“开发者模式”（Edge 名称可能为“开发人员模式”）。
4. 点击“加载已解压的扩展程序”，选择含 manifest.json 的“清译_V5”文件夹。
5. 刷新需要翻译的网页，右侧出现绿色“译”悬浮球。
已安装旧版时：把V5文件夹内的文件覆盖到原来加载的清译目录，在扩展管理页点击清译的“重新加载”，再刷新已打开的网页，可保留设置。不要同时加载两份清译。

使用
• 单击悬浮球直接翻译，再单击恢复原文；鼠标悬停时，设置在悬浮球下方展开。
• 默认微软翻译，自动识别原文语言后转为简体中文；可切换 Google 或腾讯，不需要申请 API Key。中文内容跳过，混合网页按正文段落识别。
• 译文放在正文区域，继承正文的字体、颜色、行高和宽度，原文保留。菜单、按钮和字段标签采用同行双语，译文留在原点击区域；空间不足时通过悬停提示显示完整译文，不撑高固定菜单。
• 新打开的弹框、二次弹框、popover、折叠区和可读取的网页提示会继续翻译；“保留导航栏原样”不会阻止弹层翻译。输入框提示文字可以翻译，已填写的值保持原样，恢复时保留网页自身的更新。
• GitHub个人资料、简介、代码片段等界面词按该网站的语境处理；带有身份标记的账号、作者以及仓库文件路径和当前分支按钮保持原样。
• 启动翻译后，滚动浏览、新回复加载、帖子更新会自动跟译；当前屏幕优先。
• 悬浮球可上下拖动，位置会记住。进度、暂停、继续和重试放在悬停设置里。
• 浏览器工具栏打开“清译”，可以关闭或开启“显示网页悬浮球”；该设置会记住，隐藏悬浮球不停止翻译。
• 选中外语单词、短语或句子后，译文直接显示在选区下方，随滚动跟随；点空白或按 Escape 关闭。可以关闭“划词后自动翻译”。
• 开启“自动翻译外语网页”后，新打开和刷新的外语网页自动翻译；手动恢复后，本页不会马上重新自动翻译。
• “保留导航栏原样”默认开启，减少普通网页导航、侧栏和页头的排版变化；关闭后可翻译这些区域。双语模式会增加正文高度。
• Google 和微软使用逐项识别的批量翻译；腾讯逐段识别，部分语言可能不支持，会提示手动切换引擎。当前视口正文及主动划词优先；超长正文分组，不截断。
• X 只翻译帖子正文、引用正文和帖子内的链接摘要；昵称、账号、个人资料、导航及侧栏保持原样。兼容旧版与新版正文结构。
• 隐藏辅助文字不参与整页翻译；正文被隐藏或被网页复用成非正文时，移除对应译文，迟到结果不会重新插入。
• X 悬停日期转为中文。已有完整时间提示保留原来的时钟和时区；没有提示时，使用页面日期或帖子ID中的时间，按浏览器时区补充中文完整时间。
• “恢复原网页”也会恢复时间提示。

视频字幕
• 在工具栏或悬浮球设置中开启“翻译视频字幕”，再打开网站原有字幕。当前适配 YouTube 网页字幕，以及 YouTube / X 提供的可读取字幕轨道。中文在视频内显示，保留原字幕；快进或切换字幕时清除旧句。
• 有完整可读取轨道时预取后续字幕；只有正在显示的网页字幕时，需要等待在线翻译，可能存在延迟。网页没有提供可读取字幕、字幕烧在画面里、没有字幕的视频均不支持；不进行语音识别。
• 字幕使用当前所选在线引擎。本地英文翻译模式不提供视频字幕翻译。

PDF 对照阅读
• 点击工具栏中的“PDF 翻译”或悬浮球设置里的“打开 PDF 对照阅读器”。从网页下载 PDF 后，在阅读器中选择文件。
• 文字版 PDF 最大100 MB，原页在左、中文在右；滚动时继续翻译，可切换引擎、暂停及继续。文件在本机解析，仅待译文字发送至所选翻译服务。
• 扫描图片和需密码的文档请先处理后再打开；本版本不做OCR。复杂多栏的文字顺序受PDF原始文本顺序影响，原页保留供对照。目前提供对照阅读，不导出重排后的译文PDF。

服务与适用范围
三家在线服务均在本机测试返回译文；本插件免费、免注册、免密钥。请求会将待译文字发送到所选翻译服务，不附带浏览器 Cookie。翻译缓存仅保存在扩展内存中。
免费消费级接口可能受网络、限流或服务调整影响，不是有稳定性承诺的云API。俚语、反讽和品牌词仍可能误译，可切换引擎核对。
“浏览器本地翻译”目前仅英文，且需要浏览器提供 Translator API；首次可能需要下载语言包。不支持时会显示原因；本地模式不会偷偷切换到在线服务。
适用于普通 http/https 网页中的可读取正文；浏览器内部页、商店保护页、图片、跨域框架和封闭的 Shadow DOM 暂不支持直接插入译文。PDF 使用下述独立阅读器。
如果同时开着其他网页翻译插件，请先关闭它对当前页面的翻译，以免重复叠加。

手机端
当前安装包仅适用于电脑Chrome/Edge，不能直接安装到iPhone。尚未交付清译iOS/Safari或手机脚本版本。
